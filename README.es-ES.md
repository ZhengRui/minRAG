

# minRAG: Implementación RAG Minimalista

## Visión General

minRAG es un proyecto de demostración que muestra cómo construir un pipeline de Generación Aumentada por Recuperación (RAG) limpio y minimalista sin depender de frameworks complejos como LlamaIndex. Este proyecto tiene como objetivo ofrecer una alternativa clara y personalizable a diseños complejos que pueden ser difíciles de modificar.

## Uso

Para ejecutar la implementación de minRAG y compararla con la versión de LlamaIndex:

1. Ejecute la implementación RAG minimalista:
   ```
   python rag_min.py
   ```

2. Ejecute la implementación basada en LlamaIndex:
   ```
   python rag_llamaindex.py
   ```

Ambos scripts generarán los mismos embeddings y producirán respuestas equivalentes, demostrando la efectividad del enfoque minimalista.
